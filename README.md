Gestão Comunitária ACBE

Apresentação:

O Gestão Comunitária ACBE é um MVP acadêmico desenvolvido no âmbito da disciplina Projeto de Software, do curso de Análise e Desenvolvimento de Sistemas.

O projeto tem como objetivo auxiliar a Associação Comunitária do Bairro Esplanada (ACBE), em Belo Horizonte/MG, na organização e no acompanhamento de solicitações comunitárias recebidas por seus representantes.

Objetivo:

Centralizar o registro das solicitações, permitindo sua classificação, consulta, atualização de status e acompanhamento do histórico de movimentações.

Funcionalidades previstas:

Autenticação de usuários autorizados.

Cadastro de solicitações comunitárias.

Consulta das solicitações registradas.

Atualização do status das solicitações.

Registro do histórico de movimentações.

Tecnologias previstas:

Linguagem: Python 3.12.

Framework: Django 5.2 LTS.

Interface: Bootstrap 5.3.

Banco de dados: PostgreSQL 16 ou superior.

Situação do projeto:

Projeto acadêmico para a disciplina de "Projeto de Software" da Faculdade Cruzeiro do Sul, que está em desenvolvimento. As funcionalidades serão implementadas e validadas progressivamente.

Público-alvo:

Representantes, colaboradores e voluntários autorizados da ACBE.

Observação

Este projeto possui finalidade acadêmica e utiliza dados fictícios durante o desenvolvimento e os testes.
